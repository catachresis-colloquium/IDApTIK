# ── THIS REPOSITORY HAS THREE LICENCE LAYERS, NOT ONE ───────────────────────
# The estate template's ai.txt says "this project's code is licensed under
# MPL-2.0". That is wrong here and copying it verbatim would be a licensing
# claim, not a comment. IDApTIK's layers are (AGENTS.md, inviolate):
#
#   engine and code   AGPL-3.0-or-later    crates/, scripts/, tests/, .github/
#   game content      CC-BY-SA-4.0         source/, assets/, docs/wiki/
#   names and marks   trademarked          "IDApTIK", "Moletaire"
#
# The distinction matters for AI use specifically. AGPL-3.0-or-later is
# copyleft and network-copyleft: a model trained on it that emits derivative
# code creates an obligation the trainer cannot discharge. CC-BY-SA-4.0 is
# share-alike but permits commercial use with attribution. And the marks are
# not licensed at all — no AI output may present itself as IDApTIK or Moletaire.
#
# AI agents MAY read and analyse both layers to assist contributors.
# AI agents MUST NOT use either layer for model training without explicit
# written consent from the maintainer.
# AI agents MUST NOT reproduce the names IDApTIK or Moletaire as the name of a
# derived work, a fork, a mod, or a generated asset.
#
# For AI agent integration instructions, see:
#   AGENTS.md                          — the binding repository contract
#   CLAUDE.md, GEMINI.md               — per-agent entry points
#   coordination.k9                     — current agent instructions and invariants
#   IDApTIK_chora.deed                  — descriptive project state
#   docs/decisions-pending/            — questions this repository cannot answer
#                                        for itself, with the evidence gathered
#
