`idaptik-landing-page.html` is the standalone IDApTIK startup-interface outline
provided on 2026-07-25. It is retained as an executable HTML design reference.
Its menus, status values, package counts, UMS hand-off, multiplayer controls,
and operation-launch actions are simulated in the browser; they are not wired
to IDApTIK, Universal Modding Studio, or Enaction Engine.

This page belongs to the IDApTIK game experience. Package and profile status
must eventually come from the game-owned package loader; launch operations
must use engine-neutral application data; and "UMS Workshop" must hand off to
the independent Universal Modding Studio rather than embedding the editor into
the game.

IDApTIK uses Bevy as its thin graphical frontend over `idaptik-core`
(ADR-0008). The first package round trip remains headless. The current
Gossamer-hosted client design makes Bevy the target for implementing this
outline without moving package or simulation authority into the renderer.

`water-gas-airflow.md` is the design of record for the water, gas and airflow
systems implemented in `crates/idaptik-core/src/scenario/infrastructure/`
(ADR-0013). It states what is modelled, what is deliberately qualitative, how
the two systems interoperate, and how every hazard presents a cue and a
recovery. The runtime and its three fixtures are exercised by
`crates/idaptik-core/tests/infrastructure.rs`.
